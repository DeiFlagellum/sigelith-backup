# Security policy

Please report a vulnerability in Sigelith Backup — in the encryption, the recovery script, the
time-capsule or proof code, or anything that could expose or corrupt a backup — privately, by
e-mail to **kontakt@advena-partners.com** (English, German or Polish), as listed in
<https://sigelith.org/.well-known/security.txt>. Please do not open a public issue for it.

Fixes go into the current version only. What the program sends over the internet, and when,
is described in the [README](README.md#privacy).
